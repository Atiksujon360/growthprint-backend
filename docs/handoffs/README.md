# Agent Handoffs

This directory contains handoff documentation between Devin Desktop, Codex, and other developers.

## Handoff Template

```markdown
# Handoff: [Task Name]

**Date:** YYYY-MM-DD
**From:** [Agent/Developer Name]
**To:** [Agent/Developer Name]
**Task:** [Brief task description]

## Context
[Background information about the task]

## What Was Done
[What work was completed]

## Current State
[Current state of the work]

## What Remains
[What work remains to be done]

## Next Steps
[Specific next steps for the recipient]

## Files Modified
[List of files modified]

## Known Issues
[Any known issues or concerns]

## References
[Links to relevant documentation]
```

## Handoff Guidelines

1. Use the template above for consistency
2. Provide sufficient context for the recipient
3. List all files modified
4. Document any known issues
5. Include references to relevant documentation
6. Be specific about next steps

2. **Be Specific:** List exact files and changes made
3. **Document State:** Clearly describe current state
4. **Identify Blockers:** List any blocking issues
5. **Next Steps:** Provide clear next steps
6. **References:** Link to relevant documentation
